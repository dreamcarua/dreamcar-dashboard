📐 A/B тест-план (опційно, від тижня 2)

Тижні 1-2: запускаємо default 199 ₴ на 100% трафіку — збираємо baseline ROAS/CAC.

Тиждень 3+ (опційно): split 70/30 — 70% залишається на 199, 30% — тест на 149 ₴ (нижчий вхід → перевірка чи зростуть AOV+conversion).

Stop-criteria: якщо ROAS 149-варіанта < 0.85× від 199 на 5+ днях — повертаємо весь трафік на 199.

Що не тестуємо: 249 ₴ (підтверджений програш), 99/49 для авто (порушує юніт-економіку — див. секцію 05).

Конвертація: utm_term=price149 для тест-сегмента, sticky-варіант через dcSetVariant() tracker v2.

05Що НЕ робити · anti-patterns
Підтверджені поразки
🚫
249 ₴ для premium авто −50 пп ROI vs 199 ₴. Психологічний поріг entry-ціни — 199 ₴ це «спробувати», 249 ₴ — «подумати».
⛔
99 ₴ для авто Руйнує юніт-економіку. CAC залишається таким же високим (~200 ₴ на acquisition), але AOV впав = маржа в мінус.
